# 思考链

把当前任务的思考过程画成右侧边栏里一张实时更新的**思维导图**，同时落到磁盘上的 Markdown 里，让人和 agent 读同一份东西。

## 这个插件提供什么

- **窗口右边缘的窄按钮。** 点一下右侧滑出侧边栏并切到思考链标签页；这个标签页在侧边栏的引导页里也有一张卡片。
- **是思维导图，不是列表。** 目标在最左，要求往右分叉，路线和步骤继续往外长，之间用曲线连接。滚轮按指针位置缩放；左键或中键拖动画布；**右键长按某个块可以单独拖动它**，坐标会写进文件。
- **层级按深度走。** 深度 0 = 目标，深度 1 = 用户提的要求，深度 2 = 技术路线，更深 = 具体步骤。每个块右上角标着 `GOAL` / `REQ` / `ROUTE` / `STEP`。
- **块可以直接改。** 点块在底部抽屉里改标题、改 Markdown 正文，还能加子节点、删子树（点两次确认）。文字被截断时块右下角出现 ▾，点开看全文，▴ 收起。
- **实时。** 面板打开时每 1.5 秒重读文件夹，agent 边写边显示；正在编辑时暂停刷新，保存或关闭后恢复。
- **附带技能** `thinking-tree`，规定文件夹契约、什么时候建图、做的过程中怎么持续更新、**用户的修改优先于模型记忆**，以及节点文字只交代工作、不写废话。

## 磁盘上的样子

所有节点都在当前会话工作区的同一个文件夹：

```
thinking-tree/
├── 00-goal.md
├── 01-req-panel.md
├── 01-1-route.md
└── 02-req-tree.md
```

**一个块就是一个 `.md` 文件**，全部平铺，front matter 承载结构：

```markdown
---
id: 01-req-panel
parent: 00-goal
order: 1
title: 点窗口右侧按钮弹出侧边栏
status: active
updated: 2026-01-01T00:00:00.000Z
---

纯工作笔记。
```

树的结构**只由 `parent` 决定**，文件名只是方便人看。以 `_` 开头的文件会被面板忽略。被拖动过的块会多出 `x:` / `y:`，顶栏的「自动排列」会清掉它们。

## 怎么用

1. 提一个多步骤的任务。agent 会建出 `thinking-tree/`，写目标、要求、以及每条要求下的路线。
2. 点右边缘的按钮打开面板，看它一边做一边长。
3. 想改就直接在面板里改、保存，然后让 agent 继续。它动手前会重读文件夹，按你改的做。

## 限制

- 绑定在会话的工作区目录上；解析不出工作区的会话显示空面板。
- 块默认自动排布；拖过的块固定，拖动父节点不会带着子树走，连线会拉长。
- 块上只显示标题和一行正文摘要，完整 Markdown 在抽屉里。
- 树不在会话日志里，它是工作区里的文件；分叉出来的会话共用同一个文件夹。
- 期望只有一个目标节点；多出来的根节点会作为额外的顶层块显示。
